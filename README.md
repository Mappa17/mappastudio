# MAPPA Studio — sito pubblico

Repository **pubblico** dedicato esclusivamente alla versione statica del sito MAPPA Studio, separato dal repository **privato** `Mappa17/mappa-studio`.

## Pubblicazione GitHub Pages

1. Aprire **Settings → Pages** di questo repository: https://github.com/Mappa17/mappastudio/settings/pages
2. In **Build and deployment**, impostare **Source: Deploy from a branch**.
3. Impostare **Branch: main** e directory **/(root)**; premere **Save**.
4. Attendere l'esito dell'attivazione su GitHub Pages, poi verificare l'URL **https://mappa17.github.io/mappastudio/**.

Il repository contiene `index.html`, `assets/` (hero, logo, cinque grafici SVG, CSS), `vision/`, `us/`, `gallery/` e `.nojekyll`. Le pagine interne sono ancora provvisorie. Non inserirvi informazioni riservate, credenziali o file del progetto MAPPA Platform.

Il servizio GitHub Pages è disponibile gratuitamente per questo repository pubblico. Pubblicazioni successive vanno effettuate solo dopo approvazione della versione grafica.
